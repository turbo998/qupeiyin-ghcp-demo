# 🎤 Demo 2 主持词 · 班级作业看板(10 分钟)

> **用途**:FDE 现场逐段照读;30 秒一段细化
> **核心承诺**:业务现场提一个新指标,Copilot Agent **30 秒**改完上线——原来 BA 1 周 + 前后端 1 周
> **哇点标记**:✨ 表示当场要把客户情绪推高的瞬间
> **场景代入**:第 1-3 分钟以"教研主任早会"为场景,第 4-7 分钟切到"教研主任临时插需求",最后 2-3 分钟做"工程价值复盘"
> **本 demo 最大哇点**:`5:30-6:00` 那 30 秒——Copilot 现场把家长打卡卡片加上、F5 看到结果

---

[画面] PPT 第 13 页 → Cmd+Tab 切到浏览器 → http://localhost:8000 全屏
[话术] "好,切 demo 2 屏幕。这个 demo 节奏会比较紧,10 分钟,前 4 分钟看看板,后 6 分钟看现场加需求。"
[错挥腿提示] 切屏前确认两件事:① 终端里 uvicorn 在跑 ② VS Code 已经打开 `static/index.html` 文件且 Copilot Chat 窗口在右侧。**这两件事必须在 PPT 第 13 页时就预热好,不要切屏后才找**。

## ⏱ 0:30-1:00 · 角色代入"教研主任早会"

[话术] "想象一下场景:周一早上 9 点,教研主任开早会,投影就是这一屏。她说:'本周完成率 60%,比上周还低 3 个点,各位班主任,你们班级今天散会后自己上看板核一下。'然后老师们就要打开自己班级的视图。"
[错挥腿提示] 这一段是情感铺垫,讲"早会"这个场景,客户立刻就有画面感。

## ⏱ 1:00-1:30 · 切到 G4-3 班,看板刷新

[画面] 左侧侧边栏点开"班级筛选"下拉,选 **G4-3**。整个看板在 1 秒内刷新:KPI 数字变化(总学生变成 G4-3 班的 48 个左右、完成率变化)、柱状图里 G4-3 那根高亮成橙色、待补做榜单变成 G4-3 的学生。
[话术] "假设我是 G4-3 班的英语老师,我切到我自己班。看,整个看板瞬间刷新——顶部数字变了,中间柱状图里我的班高亮橙色,待补做名单也变成我班的学生。这个交互体验就是我们要看的第一件事。"
[错挥腿提示] 切班级那一下,鼠标动作要清晰,客户要看到"下拉打开 → 选中 G4-3 → 看板刷新"完整三个动作。

## ⏱ 1:30-2:00 · 时间筛选切"近 7 天",讲数据故事

[话术] "时间切到近 7 天。看这根橙色柱子——我的班 G4-3,这周完成率比全校平均低 5 个百分点。作为老师,我会立刻想:谁没交?为什么?接下来这两个图就给我答案。"
[错挥腿提示] "低 5 个点"是个具体数字,要重读。客户听到具体差距,自己就在心里代入老师角色了。

## ⏱ 2:00-2:30 · 待补做榜单,情绪逐级展开

[画面] 镜头切到下方"待补做学生榜单 Top 10"。展示出 5-10 个学生姓名 + 缺交次数。
[话术] "待补做名单一目了然。前 5 个学生这周一次都没交,后面 5 个交了一两次还差几次。老师拿到这张表,下午就可以一个一个发消息提醒。原来这件事得手工拉 Excel,做完已经是周三了。现在每天早上 5 分钟。"
[错挥腿提示] "每天早上 5 分钟"是这一段的情感落点,要重读。

## ⏱ 2:30-3:00 · 最受欢迎素材饼图,延伸到运营动作

[画面] 鼠标切到右下角"最受欢迎素材饼图"。饼图展示 5 块,最大块是 *Hello Song* 占 28%、第二是 *Peppa Pig* 占 22%、第三是 *Hungry Caterpillar* 占 17%。
[话术] "最后一张饼图,本周这个班最受欢迎的素材是《Hello Song》,占了 28%。这个信息直接给到教研:下周可以多推几条类似的儿歌律动类素材;给到运营:可以做 Hello Song 系列的活动。一张图,两个部门联动。"
[错挥腿提示] "一张图两个部门联动"——这是从"BI 看板"升维到"业务决策"的金句,要清晰。

## ⏱ 3:00-3:30 · 收束第一段,埋下"加需求"的钩子

[画面] 鼠标回到看板顶部 KPI 行,4 个橙色卡片清晰可见。
[话术] "到这里,这都还是一个普通的 BI 看板。10 个班、500 个学生、4 个 KPI、4 张图。如果今天 demo 只看到这里,那 Copilot 也就帮你们写了一个看板而已。真正有意思的事在下半场。"
[错挥腿提示] "如果今天只看到这里"——这句话是悬念铺垫,语速要慢,留半秒停顿。客户的注意力会从"看板好不好看"切到"下半场是什么"。

## ⏱ 3:30-4:00 · 角色扮演:教研主任临时提需求

[画面] 保持在看板,鼠标停在 KPI 行不动。眼睛看向观众。
[话术] "现在我做一个角色扮演。我假装我就是你们的教研主任,我看着这个看板,我突然说:'诶,我们家长群每天也在打卡,能不能在这个看板上加一个家长打卡参与度?'——这就是业务部门最常提的那种'顺手加一个'的需求。"
[错挥腿提示] "顺手加一个"——这是关键词。每个 IT 负责人都被这种需求折磨过,他们听到这五个字就会苦笑。

---

## ⏱ 4:00-4:30 · 对照传统流程,给出"2 周"基线

[画面] 鼠标做一个"数 1 2 3"的小动作(或者画面 cut 一个对比图),口播为主。
[话术] "在传统流程里,这件事的链路是:第一步 BA 写需求文档 2 天;第二步前后端工程师评审排期 3 天;第三步后端写 API 3 天;第四步前端改 UI 2 天;第五步测试上线 2 天。加起来两周起步。这是趣配音 IT 团队过去半年的真实数据。"
[错挥腿提示] 数字要分步念出来"2 + 3 + 3 + 2 + 2 = 12 天",让客户在脑子里完成那个加法。

---

## ⏱ 4:30-5:00 · 切 VS Code,定位到 index.html

[画面] Cmd+Tab 切到 VS Code 全屏。左侧文件树展开 `demo2-classroom-dashboard/static/`,光标点中 `index.html`。右侧 Copilot Chat 窗口已经打开,光标停在输入框。
[话术] "现在我切到 VS Code。这是看板的前端代码 index.html。右边是 Copilot 的 Agent 模式聊天窗。注意我没有打开后端文件——因为后端的接口 /api/parent_checkin 我们 FDE 已经预备好了。我只让 Copilot 改前端 1 个文件。"
[错挥腿提示] 强调"只改 1 个文件"——这是控制 demo 风险的关键。如果说"Copilot 全栈写完",客户会怀疑。

---

## ⏱ 5:00-5:30 · 粘 Prompt,准备回车

[画面] 鼠标在 Copilot Chat 输入框点一下,准备粘贴。提前复制好的 prompt 出现在屏幕上。
[话术] "我现在把这段话粘进去。这就是教研主任刚才说的'加一个家长打卡指标',我把它翻译成 Copilot 能理解的精确描述,但还是中文,还是业务语言。"

**标准 Copilot Prompt(可直接粘贴)**
```
在 demo2-classroom-dashboard 项目里加一个"家长打卡参与度"指标。
后端:/api/parent_checkin 已经写好(main.py 末尾),不用动。
前端:在 static/index.html 的 KPI 行追加第 5 个 kpi-card:
  - 调用 /api/parent_checkin?days=7(如果选中了班级带上 class_id)
  - 显示 checkin_rate 字段(百分比,橙色大数字)
  - 副标题写 "近 7 天 / 已绑定 {bound_rate}%"
切换班级和时间时也要刷新这个卡。改完后我会刷新浏览器。
```

[错挥腿提示] 这段 prompt 必须提前放在剪贴板或本地一个 txt 里。**绝不能现场手打**——12 分钟的时间预算撑不住打字。

---

## ⏱ 5:30-6:00 · ✨ 哇点 1(全场最大哇点):Copilot Agent 开始改文件

[画面] 回车后 Copilot Agent 进入工作状态。左侧文件树 `static/index.html` 旁出现"●"未保存标记。右侧 Chat 区滚动出现:"I'll add a new KPI card for parent checkin..." 然后展示 diff:HTML 中新加了 `<div class="kpi-card">...</div>`,JS 中新加了 `fetchParentCheckin()` 函数。
[话术] "✨ 看!Copilot Agent 已经开始改 index.html 了。左边文件树有那个圆点,代表文件被修改了但还没保存。右边的 Chat 在实时显示它加了什么——一个 kpi-card 的 div、一个 fetchParentCheckin 的 JS 函数、一个事件绑定。整个过程 15 秒。"
[错挥腿提示] 这 15 秒一定要让客户的眼睛跟着鼠标走。指着文件树的圆点、指着 Chat 区的 diff——肢体动作大一点。如果 Copilot 这次特别快(8 秒就完了),不要慌,直接说"今天它特别快"然后立刻进下一段。

## ⏱ 6:00-6:30 · Copilot 完成,准备验证

[画面] Chat 区出现"Done. Added parent-checkin KPI card. Please refresh the browser."。`index.html` 文件被自动保存(圆点消失)。
[话术] "Copilot 说完成了,让我刷新浏览器看效果。注意它没有装新的 npm 包、没有改后端、没有改我没让它改的别的地方——它严格按照我给的边界做了改动。这是 Agent 模式跟普通补全的本质区别。"
[错挥腿提示] "严格按边界做"——这是给 IT 听的话。强调可控、可预测。

---

## ⏱ 6:30-7:00 · ✨ 哇点 2:F5 刷新,新指标跳出来

[画面] Cmd+Tab 切回浏览器,F5 刷新。看板重新渲染。KPI 行从 4 张卡变成 5 张卡——最右边新出现一张橙色大数字卡:**62.3%**,副标题"近 7 天 / 已绑定 81%"。
[话术] "✨ F5……第 5 张卡来了!家长打卡参与度 62.3%,已绑定 81%。从我说出那句需求到现在,在场所有人看着,30 秒上线。两周对 30 秒。"
[错挥腿提示] **这是整个 60 分钟最重要的 5 秒钟**。"30 秒"三个字一定要重读,然后停 2 秒不动,让客户掌声或者惊呼自己出来。如果没人有反应,补一句"这就是 AI-DLC 的样子"。

## ⏱ 7:00-7:30 · 验证交互:切班级时新卡也刷新

[画面] 左侧侧边栏切到另一个班级(比如 G3-1)。整个看板刷新,第 5 张卡的数字也变化,可能从 62.3% 变成 71.5%。再切回 G4-3。
[话术] "我再验证一下交互。切到 G3-1 班——看,新卡也跟着刷新,数字变了。切回 G4-3——回到 62.3%。切换班级和时间联动,这是我在 prompt 里要求的,Copilot 都做到了。"
[错挥腿提示] 这一段是"完整性验证",证明不是只跑通了首屏。看完客户对"30 秒"的真实性才不会怀疑。

## ⏱ 7:30-8:00 · 复盘第一段:"刚才发生了什么"

[话术] "做个 90 秒复盘。刚才发生了什么?一,我用 1 段中文 prompt;二,Copilot Agent 自己读了 index.html 找到 KPI 行的位置;三,自己写了一段 HTML 加一段 JS;四,自己保存文件;五,我们浏览器一刷新看到新卡。整个链路里,我作为'教研主任',没有写代码,没有提工单,没有等排期。"
[错挥腿提示] 5 个"自己"要并列说出来,有节奏感。

## ⏱ 8:00-8:30 · 复盘第二段:对应到三个业务收益

[画面] 镜头保持。

## ⏱ 8:30-9:00 · 提示一个"坑":FDE 提前做了什么

[画面] 切回 VS Code,打开 `main.py` 拖到末尾,展示 `/api/parent_checkin` 接口已经预先实现好(20 几行 Python)。
[话术] "我要诚实地告诉大家一件事。后端这个 /api/parent_checkin 接口,是我们 FDE 提前预制的,不是 Copilot 当场写的。为什么?因为真实场景里,FDE 跟客户对需求时,会先把'数据从哪儿来'谈清楚。一旦数据契约定下来,前端用 Copilot 30 秒搞定。"
[错挥腿提示] **诚实是这一段的关键**。客户最讨厌"魔术 demo"。把 FDE 预制的部分主动说清楚,反而能赢得信任。

## 🆘 全流程兜底速查(贴在屏幕侧边)

| 故障 | 即时动作 | 恢复时间 |
|---|---|---|
| http://localhost:8000 空白 | F12 看 console,大概率 DB 没生成 → 重跑 `./setup.sh` | 30 秒 |
| 端口被占 | `PORT=8001 ./start.sh`,口播"换个端口" | 10 秒 |
| ECharts CDN 加载慢看板没图 | 提前把 echarts.min.js 下到 static/,改 src 引用 | 提前做好,0 秒 |
| Copilot Chat 没反应 | 等 10 秒,再不动就口播"网络小波动,我直接 git diff 给你们看一份预制的"——`git checkout demo2-parent-checkin-baseline` | 10 秒 |
| Copilot 把 index.html 改坏 | `git checkout static/index.html` 还原,口播"我们重来一次" | 5 秒 |
| 浏览器 F5 没出新卡 | 检查 Copilot Chat 是否真的"Done";如果还在跑,再等 5 秒;5 秒还没出 → 切回 VS Code 让客户看 Chat 流 | 灵活 |
| 后端 /api/parent_checkin 404 | 大概率 uvicorn 没重启,F5 前 Ctrl+C 然后 `./start.sh` | 15 秒 |
| 整个 demo 崩了 | 切回 PPT 第 13 页,口播"我们今天直接讲架构,真实环境上周已经跑通,我给大家放 90 秒录屏"——切 `docs/recording-script-demo2.md` 对应的视频 | 5 秒 |

> 🎯 核心纪律:**Demo 2 严禁超过 10 分钟**。5:30-6:30 那 1 分钟是全场最大哇点,前面任何环节延误都从 8:00 后的"对照实现"段砍。
